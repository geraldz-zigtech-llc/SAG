# Submariners' Advocacy Group Website

Static website for the Submariners' Advocacy Group (SAG), built by ZigTech LLC and hosted on GitHub Pages.

**Status:** groundwork. Pages not yet built. See `docs/site-plan.md` and `.github/master-checklist.md`.

## Structure

| Path | Purpose |
|---|---|
| `assets/img/` | Images extracted from the client layout PDFs (brand, hero, board, regional, news) |
| `content/` | Page copy extracted from the client PDFs, one markdown file per page, used as build input |
| `docs/` | Client source PDFs and the site plan |
| `.github/master-checklist.md` | Build and handoff checklist (not published) |

The full README with deployment model, editing steps, and do-not-touch list is written at handoff.
